# AI Workplace Hub

Build a modern, responsive, unified SaaS dashboard named “AI Workplace Productivity Assistant” for professionals and students. Include the full requested navigation and dashboard, plus Smart Email Generator, Meeting Notes Summarizer, AI Task Planner, AI Research Assistant, and workplace AI Chatbot as integrated sections/pages within one app. Use polished light UI with dark/navy collapsible sidebar, indigo/blue/purple accents, responsive mobile drawer, editable generated outputs, clear loading/empty/error/success states, responsible AI disclaimer, and workplace-focused structured prompt logic (role, context, objective, constraints, output format) for every AI feature. Enable Lovable Cloud as needed for AI features and build a functioning end-to-end experience, not separate apps.

This project was built with [Lovable](https://lovable.dev).
